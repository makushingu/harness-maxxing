# Upgrade notes - 2.0.0a85 (instructions for Claude)

The repository moved from `rorogeno/harness-maxxing` to `makushingu/harness-maxxing` (GitHub redirects the old
address, so this is tidying, not a fix).

1. `git -C <code dir> remote get-url origin` (code dir: `maxxing status`). If it is
   `https://github.com/rorogeno/harness-maxxing(.git)`, run
   `git -C <code dir> remote set-url origin https://github.com/makushingu/harness-maxxing.git`.
   Any other address (a fork, a mirror, a local folder): leave it.
2. Do not switch the branch: an install keeps the branch it was installed on (`maxxing update` follows it).
   New installs without a key use `stable`; tell the user only if they ask why.
