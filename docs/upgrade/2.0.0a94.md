# Upgrade notes - 2.0.0a94 (instructions for Claude)

The anonymous installation counter (Settings -> Profile, card "Harness Maxxing team", "Help count the
installations") is now on by default and sends, once a day, a random id, the version, the system (e.g. Ubuntu 24.04,
x86_64) and a few health codes - never a name, an email, an IP, a server name or any content. The update already
did the only change: it turned the counter on if nobody on this server had ever answered this choice
(`register.asked` false in config.json); if someone had seen it and left it unchecked, it stays off. Nothing to do
on this server; do not change the setting yourself.

1. Look at `register` in `<state>/config.json` (read only). If `count` is true and `asked` is false (the update just
   turned it on), tell the user once, in one or two sentences: the anonymous counter is now on (what it sends, as
   above), and it is turned off by unchecking "Help count the installations" in Settings -> Profile, or for good with
   `MAXXING_NO_TELEMETRY=1` (or `DO_NOT_TRACK=1`) in the service environment (`systemctl edit claude-maxxing`, see
   the docs page License). Otherwise, say nothing about it.
