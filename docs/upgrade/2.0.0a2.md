# Upgrade notes 2.0.0a2

Summary: new default projects `system` (help, update, server, tasks, accounts, extensions) and
`tutorial`; new default jobs.

## 1. Default projects
- Check: `projects/system/topics/` contains `help`, `update`, `server`, `tasks`, `accounts`,
  `extensions`, each with `CLAUDE.md` and `memory.md`, and `projects/system/topics/accounts/accounts.md`
  exists. (`maxxing init`, run by the update, creates missing ones.)
- Do: if some are still missing, run `maxxing init --quiet` and check again. If the user had their
  own `system` project before this version with other topics, keep them; just tell the user what was
  added.
- Ask first if: a topic of the same name existed with different content - never overwrite it.

## 2. Root CLAUDE.md
- Check: the workspace `CLAUDE.md` has a section `## Default projects`.
- Do: if not, insert it before `## Memory rules` (or at the end), copying the section from
  `<CODE>/templates/workspace/CLAUDE.md` with `{{CODE_DIR}}` replaced by the code directory.
  Change nothing else in the file.

## 3. Default jobs
- Check: `maxxing cron list` shows "Check for updates" (weekly), "Morning tasks" and
  "Renewal reminder" (both disabled by default).
- Do: nothing if present (they are created once by `maxxing init`; if the user deleted one, leave it
  deleted). Mention that the two reminders can be enabled on the Crons page.

## 4. Backup of the accounts inventory
- Check: Settings -> Backup include patterns (`GET /api/backup` `include`, or
  `config.json` -> `backup.include`) contain `projects/*/topics/*/accounts.md`.
- Do: only if a backup is configured and the pattern is missing, propose to add it (it is plain
  text without secrets); add it after a yes (Settings -> Backup, or edit `backup.include`).
