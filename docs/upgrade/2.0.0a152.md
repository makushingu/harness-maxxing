## 4. The agents' sandbox on recent Ubuntu versions

  sandbox is ready, this step is done.
- Do: if the line says the sandbox is missing `apparmor` or `user namespaces`, run `maxxing agents sandbox-setup` as
  root, then `maxxing doctor` again. If something else is missing, `sandbox-setup` installs it too.
- Ask first if: always. Say it first: Ubuntu's AppArmor profile over bubblewrap kept every command of a sandboxed
  agent from running (before this version, the check said the sandbox was ready anyway). `sandbox-setup` switches
  that profile off and prints the command that switches it back on.
