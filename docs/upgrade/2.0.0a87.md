# Upgrade notes - 2.0.0a87 (instructions for Claude)

Licensed installs move to the public git repository by themselves (a few minutes after this update).

1. Run `maxxing license status`. "no license" / a git install: nothing to do, stop here.
2. A licensed install: wait until 5 minutes after the update, then `git -C <code dir> rev-parse --abbrev-ref HEAD`
   (code dir: `maxxing status`). `stable` = done: tell the user in one sentence that updates now come from
   GitHub, customizations kept. Still `main`: `maxxing doctor` (check `license`) says why; fix what it says
   (most often uncommitted changes in the code folder: `maxxing custom save "title" --why "reason"`), then
   `maxxing update` moves it first.
