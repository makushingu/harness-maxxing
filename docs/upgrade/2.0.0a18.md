# Upgrade notes - 2.0.0a18 (instructions for Claude, topic system/update)

1. Domain mode only (Caddy installed by Harness Maxxing): previews of PDFs and HTML pages are framed by the
   UI itself, which the old `X-Frame-Options "DENY"` header blocked. If `/etc/caddy/claude-maxxing.caddy`
   (or the site file written by install.sh: look for `# Harness Maxxing (written by install.sh`) contains
   `X-Frame-Options "DENY"`, change it to `X-Frame-Options "SAMEORIGIN"`, then run
   `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile && systemctl reload caddy`.
   If nginx / Apache serves the domain (reverse-proxy.conf), check the same header there.
2. PDF thumbnails need `pdftoppm` (package `poppler-utils`, installed by the Tools step). If it is missing:
   `apt-get install -y poppler-utils` (optional - without it PDFs just show an icon).
