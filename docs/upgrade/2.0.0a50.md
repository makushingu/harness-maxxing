# Upgrade notes - 2.0.0a50 (instructions for Claude)

Nothing to do. Connexxion is off until the user turns it on (Settings -> Connexxion); its state lives in
`<state>/connexxion` (mode 700) and its keys in `secrets.json` (`connexxion`). The public route
`/api/peer/v1/*` answers 404 while it is off. If Caddy restricts paths, `/api/peer/v1/*` must reach the
server like the rest of `/api/`.
