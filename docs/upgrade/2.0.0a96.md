# Upgrade notes - 2.0.0a96 (instructions for Claude)

One behavior change, nothing to run. Tell the user in two or three sentences:

- **Claude's helper agents now run in the foreground** (new config key `background_agents`, default `false`): each
  turn asks Claude to keep its subagents in the turn (several still run in parallel), so their results come back in
  the same turn instead of the turn waiting for background agents. Effect: the session stays busy (running) while
  its agents work, and a new message waits in the queue until they are done. To go back to Claude Code's own habit
  (agents in the background), set `"background_agents": true` in `<state>/config.json` (no restart needed: read at
  each turn). Only change it if the user asks; they can also ask Claude for a background agent in a message.
- **Maxxing mode (beta)** is new and off: the user can enable it in Settings -> Features -> Maxxing mode (beta).
  Do not turn it on yourself.
