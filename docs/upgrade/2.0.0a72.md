# Upgrade notes - 2.0.0a72 (instructions for Claude)

FEU's PRs #61, #66, #70, #72, #73 (audit fixes), #74, #75. Nothing to run in the workspace.

Tell the user in a few sentences (see `CHANGELOG.md`): branches and commits of the git graph open on GitHub with a
right click (long press on a phone); the dashboard cards animate; markdown and text files have a text zoom and reopen
where they were left; the plan usage bars no longer vanish and waiting messages show their text after a reload; the
settings list scrolls on a short window; 64 audit fixes (security, bugs, speed, phones and tablets).

Behaviour changes to mention only if they concern this install:
- An extension whose `page.js` / `widget.html` (or another file) is a symbolic link to a file outside its folder is no
  longer served: copy the file into the extension folder. An extension shown in error (its `api.py` failing to load,
  e.g. a missing Python package) no longer serves its page or widget: fix the error (Extensions page).
- Installing a starter pack never writes through a symbolic link (a topic folder that is a link is skipped).
- A restore on a server already in use keeps the files outside the backup list aside until the restored items are
  turned on (`maxxing backup release`), and holds settings that run a command (status line, key helper, env, project
  MCP servers) like hooks.
- The memory backup no longer saves an MCP server's password written in an address (`postgres://user:pass@…`) or
  passed as `--token=…`: after a restore, enter it again (Settings -> MCP).
- If Harness restarts while a Telegram voice note or file is being handled, the bot asks the user to send it again.
