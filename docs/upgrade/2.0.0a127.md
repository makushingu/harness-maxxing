# Upgrade notes - 2.0.0a127 (instructions for Claude)

Nothing to change in the workspace. Two things to know, to tell the user only if they come up:

- **Agents in the sandbox see less of the server.** Besides the workspace, the home folder is hidden (only git's
  settings, the shell's settings when they hold no secret, Claude's skills, package caches and installed tools stay
  readable), and so are the server's own secrets (SSH host keys, TLS certificates, the web server's files,
  databases, logs). If an agent's run now fails because it cannot read a file there, it was relying on something it
  should not see: move what it needs into its topic, or give it a key in Settings -> Keys.
- **Community library**: extensions, widgets and skills made by other people are listed on
  https://harness-maxxing.com/community (docs: Page extensions, section 5). Install one only when the user asks,
  after reading its code (the `maxxing-extension` skill says how).
