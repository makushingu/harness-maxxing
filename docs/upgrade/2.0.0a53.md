the server ignores what it left behind. If `<state>/connexxion` exists, tell the user Connexxion is gone and
offer to delete the leftovers (only with their agreement):
- the folder `<state>/connexxion` (links, threads, logs);
- the `connexxion` key of `<state>/config.json` and of `<state>/secrets.json` (keep `secrets.json` at mode 600:
  `jq 'del(.connexxion)' secrets.json > s.tmp && chmod 600 s.tmp && mv s.tmp secrets.json`).
