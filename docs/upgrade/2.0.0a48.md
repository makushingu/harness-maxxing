# Upgrade notes 2.0.0a48

Summary: the Caddy site written by older installers is brought in line (PDF previews in Files, 2 GB uploads).

## 1. Caddy site from an older installer
- Check: `maxxing doctor` shows "Caddy site settings match this version", or has no Caddy line (no Caddy site:
  Tailscale or local access): nothing to do.
- Ask first: it reloads Caddy (the UI may blink; no running turn is affected). Explain: the site sends
  `X-Frame-Options DENY`, which blocks the PDF viewer in Files, and/or refuses uploads above 500 MB while the app
  allows 2 GB.
- Do: on yes, run the doctor's fix command for `caddy_site` (two `sed` lines on `/etc/caddy/claude-maxxing.caddy`,
  then `systemctl reload caddy`), then `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile` and
  `maxxing doctor` again. If the file was customized by hand, show the lines to change instead of editing it.
