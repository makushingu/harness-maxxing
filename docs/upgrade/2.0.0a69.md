# Upgrade notes - 2.0.0a69 (instructions for Claude)

The "Your pages" extension was rewritten with the new UI kit (no emoji). Workspace templates are only copied when
missing, so refresh it only if the user never changed it:

1. If `<workspace>/extensions/pages/page.js` does not exist, stop: nothing to do.
2. `sha256sum <workspace>/extensions/pages/page.js`. If it is
   `59ca6125661e54164ee98f51659cda8421438b38fc1047b4dccc85570686730e` (the stock 1.0.0 file), copy
   `<code dir>/templates/workspace/extensions/pages/page.js` and `manifest.json` over the two files of
   `<workspace>/extensions/pages/` (the extension reloads by itself). Any other value: the user changed it, leave it.

Nothing else to do: the update rollback fixes, the dashboard cards, the starter packs and the UI kit come with the code.
