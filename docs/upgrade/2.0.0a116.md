# Upgrade notes - 2.0.0a116 (instructions for Claude)

Telegram has modes now (Settings -> Telegram -> Mode). This installation kept its current layout: `maxxing telegram
mode` prints it (`threads` when the chat already had threads, `mirror` when the web conversations were copied,
`simple` otherwise).

If Telegram is linked and the mode is `threads` or `mirror`, tell the user in one or two sentences that a **Simple**
mode exists (one chat: the alerts, and the sessions as replies - reply to a message to continue its session; agents
with the Telegram option keep their thread) and ask whether they want it. Only if they say yes:
`maxxing telegram mode simple` (it deletes the session threads and the Crons / Alerts / Notifications threads from
Telegram; the sessions stay in the web UI). Otherwise nothing to do.
