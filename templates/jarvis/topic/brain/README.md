# Jarvis's brain

Jarvis's working memory. Rewritten every night by the night pass (skill `jarvis-dream`), completed during the day by
the conversation (skill `jarvis`). Never a secret here (keys go to Settings -> Keys).

| File | What | Written by |
|---|---|---|
| `summary.md` | the essentials, loaded in every conversation (6 KB at most) | the night pass |
| `projects.md` | one entry per project: goal, state, next steps, agents, sites | the night pass (+ the day for a decision) |
| `owner.md` | goals, priorities, how the owner decides, people, commitments | the day + the night pass |
| `tasks.md` | late, today, this week, urgent; the truth stays tasks.json | the night pass |
| `inbox.md` | notes taken during the day, sorted by the next night pass | the day (emptied by the night pass) |
| `journal.md` | one entry per night: what moved, what waits for the owner (30 days) | the night pass |
